Twig is a dual-pane file manager for Android that puts every storage source in one tree, written in plain Kotlin and XML views, with no Material library and as few dependencies as possible.

<b>One tree, every source</b>

Local storage, archives, FTP, SFTP, SMB, WebDAV, S3, restic backup repositories and Jellyfin/Emby servers are all the same thing to the interface. Copying between any two of them is one code path: an SMB folder can be compressed straight into a local ZIP, and a file inside a remote archive can be streamed to an FTP server. Archives expand in place, like folders.

<b>Small and resource-conscious</b>

The 1.14.0 libre APK measures 10.28 MiB for arm64-v8a and x86_64 together, including the terminal and media player. Dependencies are added only after measuring their APK cost.

<b>Features</b>

<ul>
<li>Two panes with independent navigation, tree-style in-place expansion, grid view and thumbnails</li>
<li>Copy and move across sources with progress and cancellation; multi-file sharing and selection properties</li>
<li>Batch rename with text/regex replacement, numbering and live previews</li>
<li>Read and create ZIP/7z, including encrypted archives; browse tar and gz/xz/bz2/zst files</li>
<li>Folder compare and sync between any two sources</li>
<li>Disk usage treemap, pinch to zoom</li>
<li>Text editing with syntax highlighting and original encoding; hex, PDF, image and media viewers</li>
<li>Music playlists across sources, waveform seeking, synced lyrics and background playback</li>
<li>A git client written from scratch: status, history, side-by-side diff, worktrees and submodules, on local and remote repositories</li>
<li>Local, SSH and privileged terminals with multiple sessions; locate the shell directory in the file tree</li>
<li>Configurable file, folder, website and command shortcuts; edit paths by long-pressing or double-tapping the path bar</li>
<li>Wi-Fi sharing: Twig becomes an HTTP and WebDAV server, so a desktop can mount it</li>
<li>Website bookmarks with home-screen shortcuts, per-site display settings, custom JavaScript/CSS, element hiding, manual resource blocking and page debugging</li>
<li>Website downloads default to Downloads/twig; optional background running uses a foreground service with a notification</li>
<li>Root/Shizuku access within the local tree; Android/data access through saved SAF grants where Android permits it</li>
<li>Encrypted saved credentials, master-password app lock, fingerprint unlock and configuration backups</li>
</ul>

<b>Less usual things</b>

<ul>
<li>Browse restic backup repositories read-only, decrypted on the device, with snapshots shown as dated folders.</li>
<li>Network MP4/MKV thumbnails use container indexes to locate keyframes, fetching only small portions of the video for metadata and frame decoding.</li>
<li>Blu-ray M2TS playback, including BDAV 192-byte packets, DTS-HD Master Audio, TrueHD through its embedded AC-3 core, and PGS bitmap subtitles.</li>
<li>Jellyfin and Emby libraries browse like any other source, with playback position synced back to the server, and posters, tags, lyrics and external subtitles taken from the API instead of by reading the media file.</li>
</ul>

<b>About this build</b>

F-Droid distributes the entirely free-software <i>libre</i> build. It excludes junrar, whose UnRAR license has non-free use restrictions, so it has no RAR support. The developer’s <i>full</i> build adds read-only RAR; all other features are the same.

Twig includes no advertising, no analytics and no telemetry. Network access follows your actions: configured connections, opened websites and their resources, downloads and sharing. Websites may load their own ads or trackers.

Microphone, camera and location permissions are optional and used only when you approve a website’s request. Permission prompts identify the website and let you choose which devices to allow. Saved bookmarks can remember these decisions; temporary pages ask every time.
